# Vurio for Home Assistant

The Vurio video recorder in Home Assistant:
every camera becomes a device with its live stream, what is in front of it, and
switches for what it does.

It talks to Vurio's HTTP API with one API token, and hears about changes over
Vurio's event stream — no MQTT broker is needed.

## What each camera gets

| Entity | What it is |
| --- | --- |
| `camera.<camera>` | The live stream (over Vurio's RTSP restream) and a snapshot |
| `binary_sensor.<camera>_motion` | On while movement is an open event |
| `binary_sensor.<camera>_person`, `_vehicle`, `_animal` | On while one is in front of the camera |
| `binary_sensor.<camera>_recording` | Whether the camera is recording and producing footage |
| `sensor.<camera>_schedule` | What its weekly schedule has it doing: continuous, events only, or off |
| `image.<camera>_last_event` | The picture from the moment of its latest detection |
| `switch.<camera>_record`, `_detect` | Switch its recording and its detection |

The switches appear only for cameras the token may manage and that Vurio keeps in
its database; a camera its configuration file declares can only be changed there.

## Media browser

**Media → Vurio** lists each camera with its newest events — each a clip from just
before it began to just after it ended, with the picture of the moment — and its
recordings of the last seven days, by day and hour, in five-minute clips. Clips
are assembled by Vurio and played through Home Assistant, so the browser never
holds Vurio's token.

## Installing

1. In HACS, add this repository as a custom repository of type *Integration*, and
   install **Vurio**. Restart Home Assistant.
2. In Vurio, under **Settings → API tokens**, make a token for Home Assistant with
   `live:view`, `events:read` and `recordings:read`, and `cameras:manage` if Home
   Assistant should be able to switch cameras.
3. For live streams, turn on **Settings → Home Assistant → Serve the cameras over
   RTSP** in Vurio. Without it the cameras show snapshots only.
4. Home Assistant finds Vurio on the local network by itself: it appears under
   **Settings → Devices & services** as discovered, and asks only for the token.
   Otherwise **Add integration → Vurio**, and enter Vurio's address (for example
   `http://192.168.1.10:8099`) and the token.

The RTSP login is generated by Vurio and handed to the integration through the
token; there is nothing to type. It opens every camera, so Vurio gives it only to a
token that may watch every camera — a token scoped to some cameras gets snapshots.
